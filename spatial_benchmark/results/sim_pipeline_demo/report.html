How to read this report

  • PCE: label-free method scores (stability × agreement × spatial coherence) → pre-registered pruning → weighted co-association consensus with per-spot confidence.
  • SplitStab: domains on one half of each count (count splitting), markers tested on the other half among confident spots, repeated B times with spot subsampling; permuted negative-control genes calibrate the selection-probability threshold to an estimated FDP ≤ 0.1.
  • Kang 2025 pipeline: one run per method → aligned majority vote → SpaGCN rule (q < 0.05, in-domain fraction ≥ 0.8, fold change ≥ 1.5) on the same counts.
  • Gene-level outputs: <sample>/domain_svgs.csv (selection probability π per gene) and global_svgs.csv.
