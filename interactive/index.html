01 / Foundations

Two ways to represent a function

MLP: mix, then activate

A suitable nonlinear activation and sufficiently many units in one hidden layer can approximate a continuous target on a compact domain. The required width depends on the target and accuracy.

f̂(x)=H∑j=1vjσ(wjTx+bj)+b

KAN: transform, sum, compose

The Kolmogorov–Arnold theorem represents continuous multivariate functions through univariate functions and addition. Finite spline grids are practical approximations to those functions.

f(x)=2d+1∑q=1Φq(d∑i=1φqi(xi))

The theorem’s width is 2d+1; here d=2 gives H=5. Practical KAN width H and basis resolution are tunable. Existence results do not guarantee fitting or generalization.

Basis design

SiLU base + a learned basis expansion

φ(x)=wb SiLU(x) + wsR−1∑r=1crBr(x)
SiLU(x) = x / (1 + e−x)

Every nonlinear family uses the same SiLU base and R terms per edge, including SiLU. Cubic grid intervals = R−4; Fourier frequency pairs = (R−1)/2; Gaussian centers = R−1. Training learns wb, ws, and the basis coefficients; grid locations and frequencies stay fixed.

Gray: basis functionsOrange: 0.25 × baseTeal: example combined edge

Example curves use wb=0.25, ws=1, cr=0.6 sin(r+1). Learned curves appear in tab 04.

SiLU + cubic B-splines

φ(x)=wbSiLU(x) + ws∑ cjM₃((x−μj)/Δ)

Local support; twice continuously differentiable at simple knots. Grid intervals = R−4. Useful for smooth local changes, including approximations to thresholds or saturation.

Original KAN; genomic KAN paper. This is the paper-aligned default edge form.

SiLU + Fourier

φ(x)=wbSiLU(x) + ws∑j=1G[αjsin(jπx)+βjcos(jπx)]

Global oscillations. Frequency pairs = (R−1)/2. Captures repeating structure; the SiLU base means the full edge need not be periodic.

FourierKAN; FKAN-a drug–target prediction. SiLU is held fixed here for the basis comparison.

SiLU + Gaussian RBF

φ(x)=wbSiLU(x) + ws∑j=0G−1cj exp[−(x−μj)²/(2s²)]

Localized bell curves with decaying tails. Gaussian centers = R−1; s equals center spacing. Captures responses near selected feature values.

FastKAN replaces spline bases with Gaussian RBFs as a computational alternative. This lab does not reproduce its normalization or speed benchmark.

Basis definitions

Cubic: Δ=2/G, μj=−1+jΔ, j=−1,…,G+1. For u=(x−μj)/Δ, M₃(u)=⅔−|u|²+½|u|³ when |u|<1; (2−|u|)³/6 when 1≤|u|<2; zero otherwise. Gaussian: μj=−1+2j/(G−1), s=2/(G−1).

“Local” refers to a scalar feature value, not tissue location. Fourier edges on embeddings do not establish biological periodicity. None of these bases enforces a biological mechanism.

Hidden width and edge complexity

Hidden width H sets the number of intermediate features. Terms per edge R sets flexibility inside each nonlinear edge. Neither is learned by gradient descent in this lab.

The theorem uses H=2d+1 with unrestricted continuous functions; finite smooth bases do not inherit an exact guarantee. Here depth is fixed at one hidden layer. H is chosen in multiples of four so the MLP can match the nonlinear KAN parameter count exactly. With R terms per edge including SiLU, a nonlinear KAN has (3R+4)H+1 parameters, including separate edge scalers and node biases. The MLP has 4H+1.

Select hyperparameters using validation data or cross-validation before a final test. All comparison rows use the same total parameter count. Matched parameters do not mean equal runtime.

Slide-inspired experiment design

Which model fits which target—and at what cost?

Compare three fixed MLP activations with three KAN bases. SiLU is the shared base for all KANs and a dedicated MLP comparator. All six models have exactly the same number of trainable parameters.

Train to a validation plateau. Check validation RMSE every 20 epochs. Improvement must exceed 0.1% of the reference error (minimum 10⁻⁶) to reset patience. When patience expires, reduce the learning rate by 0.3, twice. Stop after the next plateau, or the maximum epoch limit. Restore the checkpoint with the lowest validation RMSE. A plateau is an operational stopping rule, not a guarantee of global optimality.

Implementation & references

Standalone educational regression lab; not a reproduction of the genomic benchmark. One hidden layer, squared-error loss, full-batch Adam, global gradient clipping at 5, optional L2 on all trainable parameters. Both models receive identical data per condition and seed. Fixed cubic knots; no adaptive-grid update, symbolic fitting, or pruning. Edge scalers wₛ are trained separately. Validation selects the checkpoint and stopping point. Neither test set enters training or model selection.

Original KAN · KANs for genomic tasks · FastKAN · FKAN-a

SiLU + B-splines is the default. The six-model matrix compares activation choice, basis choice, and computational cost under a shared parameter budget.
