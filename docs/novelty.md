# Novelty audit and revised SVG proposal

Targeted literature search through 22 November 2026 used the terms SVG ensemble, rank aggregation, spatial null, depth normalization, clustering stability and replicable SVG. The works below bound the claim this project can make. The project has a testable contribution, with priority and performance still open.

## What prior work already covers

| Prior work | What that means for this project |
|---|---|
| [Castl](https://doi.org/10.1093/bib/bbag074) combines SVG callers using reciprocal ranks, Cauchy p-value aggregation or permuted negative controls. The paper reports recovery of signals found by individual callers. | An ensemble, a negative-control FDP proxy, and attention to signals detected by a single caller are established ideas. Compare with author code, including its original caller set and a harmonized panel. |
| [Robust rank aggregation](https://doi.org/10.1093/bioinformatics/btr709) and [stability of ranked gene lists](https://doi.org/10.1093/bib/bbp034) address ranked-list integration and sensitivity to sample changes. [Cauchy combination](https://doi.org/10.1080/01621459.2018.1554485) gives a dependence-aware tail approximation and can detect sparse alternatives. | Rank conversion, use of multiple summaries, and perturbation stability are established. The fixed mean/max mixture is a baseline heuristic. With two families it gives the higher family 62.5% and the lower family 37.5%, a modest tilt without a standalone statistical justification. |
| [Patel et al.](https://doi.org/10.1186/s13059-025-03731-2) benchmark known patterns, null calibration and runtime. [SpaNorm](https://doi.org/10.1186/s13059-025-03565-y) models spatially varying library-size effects, and [spoon](https://pmc.ncbi.nlm.nih.gov/articles/PMC12166475/) studies mean–variance adjustment. | Null evaluation and depth adjustment already exist. The candidate contribution is to calibrate **the entire family-level decision** under shared nuisance structure and test its consequences for both types of signals. |
| [JUMP](https://doi.org/10.1093/bioinformatics/btad366), [STAREG](https://pmc.ncbi.nlm.nih.gov/articles/PMC11478871/) and the [SVG atlas](https://pubmed.ncbi.nlm.nih.gov/42922876/) address replicability or cross-slide reproducibility. | Across-section overlap is descriptive. Use existing replicability approaches as comparators if making claims across biological samples. |
| [Kang et al.](https://doi.org/10.1093/nar/gkaf303), [InSTability](https://pubmed.ncbi.nlm.nih.gov/42926708/), [DESpace](https://doi.org/10.1093/bioinformatics/btae027), and [DESpace2](https://doi.org/10.1093/bioinformatics/btag450) cover domain ensembles, domain instability, spatial cluster contrasts, or differential spatial patterns. | Any domain extension needs a clearly defined contrast and a comparison with methods that already address that target. |

## Candidate contribution worth testing

**Separate evidence that multiple detector families agree from evidence that one family detects a focal or unusual pattern. Calibrate the choice between these two routes jointly against depth-matched null data.** The review surfaced precedents for the pieces. It did not establish published priority for this specific design or establish that it improves detection.

1. Register caller families on development data from their statistics and null-score correlations. Keep family weights fixed for each evaluation panel. Collapse identical caller outputs within a family or give predeclared duplicate groups a fixed total weight. Equal family weighting alone caps a family's total influence but still changes its internal mean when one of several members is duplicated.
2. Compute two scores per gene: a mean across family ranks and a maximum family rank. Retain the supporting families and the two scores separately. Estimate their null scales using an independent calibration bank, then use a second shared bank to calibrate the combined minimum-tail decision. The shared null draw should run through preprocessing, screening, family scoring and combination in the same way as the observed inputs. This accounts empirically for selecting the stronger route where the null assumptions hold.
3. Test whether the method reduces false calls caused by a depth gradient or technically patterned spatial mask while preserving focal-gene recall. Compare with the best predeclared single caller, family mean, family maximum, flat mean, the existing 75/25 blend and all three Castl modules. Add deliberately redundant callers and assess changes in top-list membership and null rejection. Report AP and recall at comparable realized FDR on independent signal-plus-null simulations.
4. Report perturbation rank ranges, leave-one-family-out changes and separate biological replication. If disturbance of spatial neighborhoods changes a gene's rank but random spot removal does not, report that distinction. A reproducible technical artifact can score highly on all stability summaries. Evidence for reliability requires independent samples, null controls and explicit technical sensitivity.

**Calibration gate.** A fitted null model can be misspecified. Evaluate model-based nulls with depth offsets and, where exchangeability is defensible, restricted permutation within technical strata, using independent mixed-null simulations and nuisance-only controls. Pair these with alternative preprocessors such as SpaNorm. Record attainable Monte Carlo p-value resolution before multiplicity correction, and treat any tail extrapolation as a separate model to validate. Use candidate rankings as the deliverable until error calibration is supported.

## What the latest results change

The expanded real-data audit found higher matched top-list overlap for Moran's I than the 75/25 ensemble in every comparable pair. A graph baseline is therefore the initial reference for reproducibility. Cross-section concordance cannot establish that either score selects more true SVGs. The aggregate could still add value for focal signals, but that hypothesis requires known truth and pattern-specific comparisons. The prototype kernel also generates tied scores after clipping and CSV rounding. Prioritize official SPARK-X and an additional genuinely different detector such as nnSVG or Spanve before tuning weights. Check focal neighborhoods, multiple scales, count depth, mitochondrial gene sensitivity and altered masks. Freeze any changes before independent donor/platform evaluation. ## How the design transfers to other SVG types

| Target | What can be reused | What must change |
|---|---|---|
| Overall SVG | Family weighting, joint calibration, rank stability and replication. | The unit is a gene per section. Define whether biology driven by cell composition is included. Use a location-dependence null conditional on declared technical covariates. |
| Domain marker | The ensemble can nominate spatial candidates and organize evidence by family. The existing [split-and-gate pilot](../spatial_benchmark/FRAMEWORK.md) can propagate map uncertainty. | The unit becomes gene × domain with a signed contrast, such as layer 5 versus layer 4. Aggregate callers testing that same contrast. Use independent/annotated domains or count splitting and test signs and effects when map boundaries are perturbed. If overall rankings are used for screening, use an independent split or validate the full screening-to-testing procedure for gene–domain error. A small-domain marker can be weak on a whole-section ranking. |
| Cell-type-specific SVG | Rank integration and perturbation summaries transfer to callers with aligned conditional hypotheses. Overall SVGs can help triage follow-up. | The unit becomes gene × cell type. Use annotated cells with a within-type spatial graph, or model spot mixtures and propagate deconvolution uncertainty. Use a within-type null that retains cell-type composition, require coverage for rare types, and benchmark against [ctSVG](https://doi.org/10.1186/s13059-025-03870-6), [STANCE](https://doi.org/10.1038/s41467-025-57117-w) or [C-SIDE](https://doi.org/10.1038/s41592-022-01575-3), as appropriate. A composition-driven overall SVG may have zero within-type effect. Opposite effects in two types may cancel in the overall signal. Avoid using the overall list as a required gate. [Cell-type benchmark](https://doi.org/10.1093/bib/bbag190) |

For the extensions, generate simulations where marginal spatial variation and conditional effects are deliberately decoupled. Include composition-only genes, opposite within-type effects, rare-cell-type signals, and small domains. Estimate precision and recall for the corresponding gene–domain or gene–type hypotheses. These extensions are proposed.
